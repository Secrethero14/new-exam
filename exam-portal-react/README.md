# Textile & DU Tech Exam Portal (React + TypeScript + Tailwind CSS)

সম্পূর্ণ সিস্টেমটি সফলভাবে আধুনিক React, TypeScript এবং Tailwind CSS স্ট্যাকে মাইগ্রেট করা হয়েছে।

## 🚀 প্রধান সমাধান ও ফিচারসমূহ:

1. **ফোল্ডার ব্যাক বাটন এবং রিফ্রেশ বাগ ফিক্স:**
   - ফোল্ডারে ক্লিক করলে URL Hash (`#folderName`) ও History API (`pushState` / `popstate`) সিঙ্ক হয়।
   - মোবাইলের ব্যাক বাটন চাপলে বা ব্রাউজারে রিফ্রেশ দিলে ইউজার বের হয়ে যাবে না; ঠিক ওই ফোল্ডারেই থাকবে অথবা আগের ধাপে ফিরে যাবে।

2. **গুগল শিট ও গিটহাব জেসন ইন্টিগ্রেশন:**
   - আপনার বর্তমান `https://textile-du-tech-exam.vercel.app/public/questions/` ডাটা স্ট্রাকচার সম্পূর্ণ অক্ষুণ্ণ রাখা হয়েছে।

3. **ল্যাটেক্স ও কাটেক্স (KaTeX) রেন্ডারিং:**
   - বাংলা ও ইংরেজি টেক্সটের ভেতরে থাকা `$x^2$`, `$$...$$`, `\(...\)`, `\[...\]` যেকোনো সমীকরণ নির্ভুলভাবে রেন্ডার করার জন্য ডেডিকেটেড `KaTeXRenderer` কম্পোনেন্ট যুক্ত করা হয়েছে।

4. **ফায়ারবেস (Firebase Modular v10):**
   - আধুনিক মডুলার SDK দিয়ে Auth ও Firestore হ্যান্ডল করা হয়েছে।
   - রেজাল্ট সেভ ও মাত্র ৩টি রিড খরচে সার্ভার-সাইড কাউন্ট কুয়েরি দিয়ে র‍্যাঙ্ক ক্যালকুলেশন অক্ষুণ্ণ রাখা হয়েছে।

5. **প্রিন্ট / পিডিএফ সাপোর্ট:**
   - Native Print অপ্টিমাইজড সিএসএস অন্তর্ভুক্ত।

## 🛠️ কীভাবে চালাবেন (Run Instructions):

প্রজেক্ট ফোল্ডারে গিয়ে টার্মিনালে নিচের কমান্ডগুলো চালান:

```bash
# ডিপেন্ডেন্সি ইন্সটল করুন
npm install

# ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev

# প্রোডাকশন বিল্ড তৈরি করুন
npm run build
```

## 📁 ফাইল স্ট্রাকচার:
- `src/pages/HomePage.tsx` -> হোম পেজ, ক্যাটাগরি ফোল্ডার, পেমেন্ট ও অথেন্টিকেশন
- `src/pages/ExamPage.tsx` -> লাইভ এক্সাম, টাইমার, অ্যানসার লক, প্রগ্রেস বার
- `src/pages/ResultPage.tsx` -> রেজাল্ট, র‍্যাঙ্ক, ফিল্টারিং ও ব্যাখ্যা
- `src/pages/ProfilePage.tsx` -> স্টুডেন্ট প্রোফাইল ও এক্সাম হিস্ট্রি
- `src/utils/KaTeXRenderer.tsx` -> ম্যাথ সমীকরণ রেন্ডারার
- `src/firebase.ts` -> ফায়ারবেস কনফিগারেশন
